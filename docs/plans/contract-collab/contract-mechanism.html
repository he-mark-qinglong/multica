关键纪律（P0 已落地）

  • 无契约不派单：每个 issue 顶部必须嵌入 task-contract-template.yaml 代码块，否则 worker 有权拒绝 claim。
  • CLAIMED_DONE ≠ DONE：agent 自称完成仅进入 ATTESTING，必须提交可复现证据（命令、输出、attestation_id）。
  • SIGNOFF 需 attestation_id：L4/L5 签核必须引用 evidence gate 的 attestation_id，否则 signoff 无效。
  • 引用必 pin SHA：metric_refs / 代码引用必须包含 Git SHA 或 data_as_of，防止前视偏差（look-ahead）。
  • env_fail_check_first：失败先检查环境 / 路径 / 磁盘，再归因于策略或代码。
  • comment schema：所有评论首行必须是 [TYPE] ISO8601 摘要，TYPE ∈ STATUS/DECISION/EVIDENCE/KILL/ESCALATE/SIGNOFF/NUDGE/NOOP。
