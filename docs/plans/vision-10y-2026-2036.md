## 0. 北极星

**到 2036 年，建成一个自我进化的自治量化研究组织**：机器完成「假设生成 → 严格验证 →
组合运营 → 退役清算」全链路；人类只设定方向、裁决例外、承担资金决策。

衡量成功的不是任何单一策略的盈亏，而是两个复利曲线：

1. **验证策略的累计产出**——经全管线验证、费后为正的存量策略组合
2. **知识资产的累计密度**——每一次 KILL 都让下一次研究更便宜（不重复犯错）

## 0.1 三条十年不变的第一性原理（从已有伤疤提炼）

- **没有策略能活十年，能活十年的是发现-验证-淘汰策略的系统。** 所有策略终将会死
  （regime 变化、拥挤、成本侵蚀），组织的目标是死亡速度 < 发现速度。
- **成本与执行决定生死。** H 族毛利 2.5bps/笔、T01/T04 双双死于 cost-cap：毛 edge
  不过成本 2 倍的想法不配写代码。这条已经烧进 SPEC 预检。
- **不沉淀等于没发生。** T06 同一家族被重试 3 次才死透，因为 kill 上下文跨会话漂移。
  ledger/JOURNAL/graveyard 的存在就是为了这个组织从不犯第二次同样的错。

## 1. 三阶段拆解

### 阶段一 2026–2027：地基与自持循环

让系统在没有人类日常干预的情况下把日循环转起来，并产出**第一个**通过全管线的策略。

- 基建 sprint（当前 68 任务）：统一引擎、fee shock 入管线、adapter 收敛、compare 可读、
  部署自动化、paper 重写、swarm 回收机制
- 日循环自持：research-scout → 筛选 → 实现 → 验证 → 判决 → epoch-retro，连续 90 天
- 验证管线硬化：server gate 修复上线、双框架 CV 真实可跑、fee shock 成为默认
- 策略目标：≥1 个策略通过全 G 门 + 双框架 + 60bps fee shock，进入 paper trading
- **阶段验收（2027 年中）**：连续 30 天无人干预的日循环产出 + 1 个 paper 中的全验证策略
  + 重复犯错率 = 0（无已 KILL 家族被重做）

### 阶段二 2027–2029：组合与执行升级

从「找到单个策略」升级为「运营一个组合」，并解开执行层这个最大的成本枷锁。

- 组合层：3–5 个低相关验证策略的权重管理、相关性监控（T07 方向的成熟化）、
  组合级回撤预算
- 执行层：maker-side execution 研究——这是 T01/T04 两具尸体共同指向的复活钥匙，
  一旦有效成本从 taker ~11bps 降到 maker ~1bps，整个 microstructure 家族重新开门
- 数据资产：aggTrades 多年库、多交易所覆盖、数据新鲜度自动化（日更）
- 研究工厂化：稳定吞吐 = 每周 ≥5 个 SPEC 预检、≥2 个全管线验证、判决周期 <48h
- **阶段验收（2029 年中）**：组合层面费后 Sharpe >1.5 且最大回撤 <15% 持续 12 个月
  （paper 或小仓实盘）；maker 执行若验证成功，microstructure 家族重开 ≥3 个 SPEC

### 阶段三 2029–2036：自治与规模

系统从「自动运行」进化为「自我改进」，资金规模跟随证据而不是野心。

- 多市场：多交易所、多资产类别（股票/期货/期权按数据可得性）
- regime 自适应：系统自动识别市场状态并调整策略权重，人工不再干预配置
- 元进化：autopilot-prompt-tuner 的终极形态——研究流程本身的参数（SPEC 通过率、
  判决周期、家族耗尽速度）成为优化对象，系统改写自己的研究方法论
- 资金纪律：只有当阶段二的组合证据在实盘中复现 ≥12 个月，才逐档放大真实资金；
  证据不出现就永远停在研究模式——成本控制让这同样可以接受
- **阶段验收（2036）**：系统在无人干预下完成 ≥10 个完整的
  「研究 → 验证 → 上线 → 退役」策略生命周期，且有审计链证明每次判决符合当时的证据

## 3. 衡量体系（KPI 树，epoch-retro 每日采集、年报汇总）

- **研究吞吐**：SPEC/周（预检后）、全管线验证/周、判决周期中位数
- **研究质量**：全管线通过率（预期 <10%，太高说明门禁松）、KILL 复活成功率、
  **重复犯错率**（已 KILL 家族被重做的次数，目标恒 0）
- **知识资产**：`_shared/` 可复用组件数、graveyard 条目/证据完备率、
  知识图谱（GitNexus）索引新鲜度
- **组合业务**：费后 Sharpe、最大回撤、容量估计、策略间相关性
- **成本纪律**：token 成本/每个出 verdict 的策略、人工介入小时/周（目标 <1h）

## 5. 十年不变的原则清单（任何年度的计划都不得违反）

1. 验证唯一权威路径——预注册 → walk-forward OOS → 双框架 CV → fee shock → G 门 → 独立签核
2. 并行纪律——基础设施 swarm 化，策略思路单线程
3. 成本纪律——caocao-m3 为唯一默认模型；cost-cap 预检先于代码
4. 证据文化——KILL 有奖、必须有证据指针和复活条件；NOOP 是合法产出
5. 人类例外通道——m3 判不了的走 ESCALATE，永远不升级模型解决判断问题
6. cycle-46——家族耗尽即换轴，禁止参数扫荡式续命
